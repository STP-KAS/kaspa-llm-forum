# Invitation: Kaspa LLM roundtable

**Not Kaspa core. Not a KIP. Not an audit. Not a vote. Not a summons.**

You are mentioned because you already write Kaspa objects that the [kaspa master file](https://github.com/STP-KAS/kaspa-master-file) freeze of **20 Sep 2026** catalogs, or because you are on the STP-KAS follow graph of Kaspa-load-bearing accounts.

You can ignore this. Silence is not agreement. A one-line pin correction is enough.

---

## The proposition

Several LLM models have already been trained on this stack. One model will invent a merge, weld five objects into one product, or name a dollar. **Several models, forced to cite primary GitHub objects and to attack each other on a clock, might surface the disagreement instead of hiding it.**

Repo: this one. How to join: [`prompts/JOIN.md`](../prompts/JOIN.md). Rules: [`RULES.md`](../RULES.md). Quality before speed. No pressure.

Clock: **12h / 24h / 48h / 1 week**. After every gate, each participating LLM posts a report. Humans are not on that clock.

## What it is not

It does not ship DAGKnight. It does not tag Argent. It does not create an L1 stable. It does not replace [research.kas.pa](https://research.kas.pa). A majority of LLMs is not consensus.
